PROJECT_01 ACADEMIC & APPLIED RESEARCH

InternMatch DSS

Sistem Pendukung Keputusan Multi-Kriteria untuk Rekomendasi Penempatan Magang Mahasiswa

KONTEKS PERMASALAHAN

Proses pencocokan antara kompetensi mahasiswa dengan kriteria spesifikasi mitra industri magang sering kali terbentur bias subjektif dan ketidaksesuaian kualifikasi. Dibutuhkan engine analitis yang dapat mengukur kompetensi teknis, preferensi bidang, rekam akademik, dan kuota penerimaan secara proporsional dan transparan.

PERAN & KONTRIBUSI SAYA

Bertanggung jawab atas formulasi logika sistem pendukung keputusan (DSS), perancangan matriks pembobotan kriteria, normalisasi nilai kandidat, serta implementasi logika penilaian dan perankingan pada modul backend.

METODOLOGI DSS YANG DIAPLIKASIKAN

Menggunakan pendekatan Multi-Criteria Decision Making (MCDM) seperti AHP (Analytic Hierarchy Process) untuk penentuan bobot kepentingan relatif antar-kriteria, dikombinasikan dengan TOPSIS / Profile Matching untuk perangkingan alternatif berdasarkan jarak geometris terhadap solusi ideal.

STACK TEKNOLOGI

Python / PHP MySQL Relational DB MCDM Matrix Computation REST API Responsive Front-End

TANTANGAN REKAYASA & SOLUSI

Tantangan utama terletak pada konsistensi matriks perbandingan berpasangan (Pairwise Comparison Consistency Ratio < 0.1) serta normalisasi data kualitatif mahasiswa (portfolio, soft skills) menjadi variabel numerik terstandarisasi tanpa kehilangan konteks aslinya.

HASIL & INSIGHT UTAMA

Sistem berhasil menghasilkan rekomendasi penempatan magang yang dapat diaudit perhitungannya (white-box decision), mereduksi ambiguitas seleksi, serta memberikan laporan skor kompatibilitas yang jelas baik bagi koordinator magang maupun mahasiswa bersangkutan.

Tautan Proyek: Live Demo GitHub Repo
Algoritma: Pembobotan Multi-Kriteria & Matriks Perankingan
PROJECT_02 WEB APPLICATION & INVENTORY SYSTEM

MySembako

Platform Terpadu Manajemen Stok, Distribusi, dan Transaksi Komoditas Sembilan Bahan Pokok

KONTEKS PERMASALAHAN

Pengelolaan pasokan sembako pada toko fisik konvensional rentan terhadap pencatatan ganda, ketidaksesuaian stok fisik dengan pembukuan, keterlambatan restock komoditas kritis, dan fluktuasi harga beli yang cepat. Diperlukan aplikasi terpusat untuk memantau inventaris secara real-time dan mengelola transaksi dengan akurat.

PERAN & KONTRIBUSI SAYA

Sebagai pengembang utama (Full-Stack Developer) yang merancang skema database relasional untuk entitas barang, satuan multi-kemasan, log pergerakan stok, modul kasir/transaksi, serta dasbor pemantauan stok minimum.

FITUR UTAMA & ALUR OPERASIONAL

Pencatatan batch masuk dan keluar (FIFO/rata-rata), notifikasi batas minimum stok sembako, pencetakan rekap transaksi kasir harian, serta visibilitas katalog barang bagi konsumen/karyawan.

STACK TEKNOLOGI

Web Stack (Node.js / PHP) MySQL Relational DB HTML5 / Modern CSS / Vanilla JS RESTful Endpoints Transaction ACID Safe

TANTANGAN REKAYASA & SOLUSI

Menjaga integritas data saat transaksi penjualan berlangsung serentak (concurrency control) agar kuantitas stok barang tidak menjadi negatif, serta merancang skema relasi tabel yang fleksibel untuk berbagai satuan barang (karton, pack, kilogram, liter).

HASIL & INSIGHT UTAMA

Aplikasi menyederhanakan siklus rekonsiliasi stok harian dari hitungan jam menjadi hitungan menit, menghilangkan selisih stok manual, serta memberikan visibilitas margin keuntungan per komoditas secara instan.

Tautan Proyek: Live Demo GitHub Repo
Fokus Sistem: Integritas Transaksi & Pelacakan Mutasi Stok
